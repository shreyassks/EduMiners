# Report reference sheet — EduMiners

Working aid only. Every number below is copied straight from the pipeline
outputs in `outputs/` (regenerated by `python src/run_all.py`, seed 42).
Use it to look up figures while you write `report.pdf` in your own words.
This file is **not** the report and should not be submitted.

Source files are named in each section so you can cite them.

---

## 1. Data scope (primary)

- Dataset: Akshara GP Maths Contest.
- Rows scored: 1,379,087 student sittings.
- Grades: 4, 5, 6.
- Years: 2022-23, 2023-24, 2024-25.
- Districts: 31 contest districts.
- Each row: Q1–Q20 scored 0/1 → `pct_correct`.
- Overall student-weighted accuracy: **53.1%**.

External context datasets (see `manifest.yml`):
- NFHS-5 district health/development indicators.
- SSLC 2025 Class-10 maths pass rates.
- Bridged to contest districts via `ACSEL/district_crosswalk.xlsx`.

## 7. Diagnostic model
Source: `outputs/tables/model_metrics.csv`

- Model: OLS, accuracy ~ standardized development index.
- Development index = mean z-score of `female_ever_school_n5`,
  `improved_sanitation_n5`, `women_10yr_schooling_n5`.
- n = 31 districts, random seed = 42.
- R² = **0.4271**.
- Standardized coefficient: +1 SD of the development index ≈ **+5.85 pp** accuracy
  (`std_coef_per_sd` = 0.0585).
